# Developer documentation

How to use and run Lotse is described in the [handbook](https://bennet0904.github.io/lotse/) (sources in [`guide/`](../guide/)). This folder is for people working on Lotse itself:

- [Writing an adapter](adapters.md): the adapter interfaces, the contract suite, recorded responses and live tests.
- [Testing](testing.md): the test levels and what each needs.
- [Implementation status](implementation-status.md): what is verified against real systems, and what is not.
- [Architecture decision records](adr/): the decisions that shape Lotse.
