# 10. English as the project language (D10)

Status: Accepted

## Context

An international open-source project needs one working language.

## Decision

Code, comments, commits, issues, documentation and the default user interface are in English. Other languages, starting with German, come as translations; the user interface's message catalogue is typed so that a missing translation is a compile error.

## Consequences

Contributors and users worldwide can participate; translations are community contributions.
