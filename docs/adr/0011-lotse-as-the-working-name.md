# 11. Lotse as the working name (D11)

Status: Accepted

## Context

Work had to start before branding was settled.

## Decision

Packages, CLI and repository use the name "Lotse". A one-time rename is planned before the first public release.

## Consequences

Names appear in package names, environment variables (`LOTSE_*`), labels (`dev.lotse.*`) and file locations; the rename has to cover all of them in one release.
