# 3. Apache License 2.0 (D3)

Status: Accepted

## Context

Companies must be able to use and extend Lotse without legal uncertainty, including in products they sell.

## Decision

Lotse is licensed under the Apache License 2.0. Contributions are accepted under the Developer Certificate of Origin; there is no Contributor License Agreement.

## Consequences

Permissive use with an explicit patent grant. Bundled third-party code must carry its notices; the desktop bundle collects them in `THIRD_PARTY_LICENSES.txt`.
