# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/bennet0904/lotse/discussions) or an [issue](https://github.com/bennet0904/lotse/issues).
- **Bugs:** open an [issue](https://github.com/bennet0904/lotse/issues) with what you did, what you expected, what happened, and the version (**Settings → This installation**). Copy error messages as text. Never include tokens or keys.
- **Security problems:** please report them privately, see the [security policy](https://github.com/bennet0904/lotse/security/policy).
- **Status of the provider connections:** the [status page](https://bennet0904.github.io/lotse/status/) shows the nightly test results for each provider.

## Contributing

Lotse is open source under the Apache License 2.0. Improvements to this handbook are welcome: every page has an _Improve this page_ link at the bottom. For code, see the [contribution guide](https://github.com/bennet0904/lotse/blob/main/CONTRIBUTING.md).
